## Key Product Decisions

- **Target problem:** Difficulty deciding what to study next when managing multiple learning commitments.
- **Proposed solution:** Explainable, personalised next-task recommendations.
- **Initial target users:** Online learners managing multiple courses.
- **North Star Metric:** Weekly Active Learning Days.
- **Validation approach:** Controlled experiment comparing personalised recommendations with a basic task list.

## Project Limitations

This is a self-directed product discovery case study. The data analysis uses historical OULAD data. Product hypotheses and proposed experiments have not yet been validated through a live product launch.
