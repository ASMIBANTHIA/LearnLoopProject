
# LearnLoop — User Journey

## Target user

A learner managing multiple online courses alongside other daily responsibilities.

## User scenario

A learner has three active courses, two upcoming deadlines and only one hour available to study today.

## Journey

### 1. Onboarding
- Learner creates an account.
- Adds their active courses.
- Enters upcoming assignments and deadlines.

**User need:** Get all learning commitments into one place.

### 2. Set availability
- Learner specifies available study time.
- LearnLoop understands how much time is available today.

**User need:** Create a plan that fits their actual schedule.

### 3. View recommendations
- LearnLoop reviews pending tasks.
- Considers deadlines, estimated effort and course priority.
- Recommends the next task.
- Explains why it was selected.

**User need:** Avoid spending time deciding what to study.

### 4. Complete a task
- Learner starts the recommended task.
- Marks it complete or updates its progress.
- LearnLoop refreshes the recommendations.

**User need:** Make progress without constantly reorganising the schedule.

### 5. Recover from falling behind
- Learner misses a planned study session.
- LearnLoop recalculates priorities.
- Suggests a manageable next action.

**User need:** Recover without feeling overwhelmed by an accumulating task list.

## Critical user experience principle

LearnLoop should reduce the mental effort required to plan learning, not create another system that learners must constantly maintain.

## Potential friction points

- Manually entering multiple courses and deadlines.
- Incorrect estimates of task duration.
- Changing daily availability.
- Recommendations that do not match learner preferences.
- Learners ignoring repeated suggestions.

These friction points should be addressed through usability testing.
